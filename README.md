# SUPERGLUEDIN

> The World's Most Inconvenient Professional Network

An intentional bad-design parody web application featuring deliberate ragebait UX, inverted keyboard navigation, Atbash ciphers, tolerance-based secret shape matching, sequential real-style CAPTCHA modal sessions, self-rearranging action buttons, ridiculous confirmation chains, occasional reversed scrolling, and a fully editable profile.

## Quick Start

### 1. Install Dependencies
`ash
npm install
`

### 2. Run Development Server
`ash
npm run dev
`
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 3. Build for Production
`ash
npm run build
`
The output will be generated in the dist/ directory.
